# Blood Donor Availability - Data Science

## Objective
Predict whether a blood donor is available or not available.

## Model
Random Forest Classifier

## Features
- Blood Group
- City
- Months Since First Donation
- Number of Donations

## Target
- Availability
  - Available
  - Not Available
  ## Model Evaluation

The project uses a Random Forest Classifier to predict blood donor availability.

### Data Split
- Training: 70%
- Validation: 15%
- Testing: 15%

### Test Results
- Test Accuracy: 51%
- No F1-score: 0.49
- Yes F1-score: 0.53

The current model is considered a baseline model. Further feature engineering and model optimization may improve the prediction performance.
