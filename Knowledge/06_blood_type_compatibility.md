# Blood Type Compatibility

## Understanding Blood Types

Blood type is determined by the presence or absence of specific antigens on red blood cells. The two most important systems are:

- **ABO system** — A, B, AB, or O
- **Rh factor** — positive (+) or negative (−)

## The ABO System

| Blood Group | Antigens on Red Cells | Antibodies in Plasma |
|-------------|----------------------|---------------------|
| A | A antigen | Anti-B |
| B | B antigen | Anti-A |
| AB | Both A and B | Neither |
| O | Neither | Both anti-A and anti-B |

## Rh Factor

- **Rh-positive** — has the D antigen
- **Rh-negative** — does not have the D antigen

## Red Blood Cell Compatibility

| Donor Blood Type | Can Donate To |
|------------------|---------------|
| **O− (Universal donor)** | Any blood type |
| O+ | O+, A+, B+, AB+ |
| A− | A−, A+, AB−, AB+ |
| A+ | A+, AB+ |
| B− | B−, B+, AB−, AB+ |
| B+ | B+, AB+ |
| AB− | AB−, AB+ |
| AB+ (Universal recipient) | AB+ only |

## Plasma Compatibility

Plasma compatibility is the **opposite** of red cell compatibility:

- **Type AB plasma** is the universal plasma donor (can be given to any patient)
- **Type O plasma** can only be given to O patients

## Why Compatibility Matters

Transfusing incompatible blood types can cause a severe and potentially fatal immune response. All donated blood is meticulously typed and cross-matched before transfusion.

## Universal Donors and Recipients

- **Universal red cell donor**: Type O− — critical in emergencies when there is no time to determine the patient's blood type
- **Universal plasma donor**: Type AB
- **Universal recipient**: Type AB+
